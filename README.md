Opis aplikacji

PROTRONIX-HomeAssistant to prywatna integracja Allegro REST API z systemem Home Assistant.

Aplikacja umożliwia właścicielowi konta sprzedawcy Allegro odczytywanie informacji o zamówieniach i prezentowanie ich na lokalnym wyświetlaczu LCD.
Funkcjonalności

    Pobieranie liczby zamówień oczekujących na wysyłkę.

    Odczytywanie nazw zakupionych produktów.

    Odczytywanie liczby sztuk produktów w zamówieniach.

    Wyświetlanie informacji o zamówieniach na ekranie LCD 16×2.

    Automatyczna aktualizacja danych w Home Assistant.

Autoryzacja

Aplikacja korzysta z OAuth 2.0 Allegro REST API i uzyskuje dostęp wyłącznie po autoryzacji właściciela konta.
Przeznaczenie

Integracja jest przeznaczona do prywatnego użytku właściciela konta sprzedawcy. Nie jest udostępniana innym użytkownikom.
Bezpieczeństwo

Dane uwierzytelniające i tokeny API są przechowywane lokalnie w systemie Home Assistant i nie są publikowane w repozytorium.
